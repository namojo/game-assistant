# 거버넌스 5문서 골격

## 1. AI 활용 원칙 (1장)
- 학습 데이터 범위: 자사 IP 원화·스프라이트·로그로 한정. 외부 데이터 학습 모델은 컨셉 탐색에만.
- 사람 유지 영역: 핵심 캐릭터 원화, 최종 밸런스 수치 확정, 배포 승인, CS 발송 승인.
- 유저 공개 범위: (택1) 전면 공개 / 변형·배경에 한해 공개 / 비공개+스토어 고지 의무 준수. 스팀 진출 시 고지 필수.
- 시상식·전시 규정 확인 절차.

## 2. 아트 스타일 가이드
팔레트(등급별), 선 굵기, 실루엣 규칙, 해상도·여백, 금지 표현. 자동 검수 기준의 원본. 없으면 컨설팅 2단계 초입에 작성.

## 3. 에이전트 권한 정책 (등급표)
| 등급 | 예 | 자동 실행 | 승인 |
|---|---|---|---|
| L0 읽기 | 리뷰 분류, 곡선 diff 리포트 | O | 불필요 |
| L1 초안 | CS 답변 초안, 공지 초안, 변형 에셋 후보 | O(초안까지) | 발송·임포트는 사람 |
| L2 변경 | 시트 수정, 코드 PR 생성 | O(PR/브랜치까지) | 머지·반영은 사람 |
| L3 배포 | 스토어 제출, 서버 배포 | X | 항상 사람 |

## 4. 데이터 정책
유저 식별 정보 외부 API 전송 금지, 로그 익명화 규칙, 외부 모델 API에 보내는 데이터 범위(리뷰 텍스트 O, 결제 식별자 X), 보관 기간.

## 5. 역할 정의서
아트 디렉터(큐레이션·리터치·스타일 가이드 소유) / QA 오너(시뮬레이터 결과 해석·배포 승인) / 에이전트 운영자(하네스 관리·스킬 라이브러리·권한 정책 집행). 기존 직무에서의 전환 경로를 함께 적는다.
