# 기획서 목차 (분량 가이드: A4 12~18장)

```
표지: {대상사} AX 컨설팅 기획서 / 제안 조직 / 일자 / 문서 버전
0. 경영진 요약 (1장) — 별도 파일로도 제공
1. 제안 배경 (1장) — 시장 3줄·지역 3줄·대상사 3줄. 도구 이름 없음
2. 우리가 이해한 {대상사} (1~2장) — 확인된 사실 표, 스토어 리뷰에서 읽은 신호, 한 문장 정의("9명이 8년째 굴리는 콘텐츠 공장"), (추정) 표시 유지
3. 지방 게임사의 구조적 이슈와 역설적 강점 (1장)
4. 진단 가설 (1장) — 업데이트 사이클의 병목 상위 5, Quick Win 후보 3. "첫 미팅·진단에서 검증"
5. 접근 방법 (1~2장) — 진단→연결→증명→확장→내재화 논리, 컨설팅 원칙 5개(병목 먼저·측정 가능만·역할 재정의 선행·단일 진입점·자사 데이터 우선)
6. 제안 범위와 단계 (2장) — 0 진단 / 1 Quick Win / 2 파이프라인화 / 3 조직화. 단계별 기간·활동·산출물·고객 측 참여
7. 3년 시나리오와 AX 우선순위 (1장) — A/B/C 표, "첫 미팅에서 무게 중심 확인"
8. 신작 프로토타이핑 트랙 (1~2장) — 시나리오 C 옵션. 시뮬레이터-퍼스트 원칙, 기존 자산 재사용, 별첨 GDD·빌드 플랜 안내
9. 성과 지표 (1장) — 4대 KPI 표(측정 방법·기준선 측정 시점·목표 방향) + 보조 지표 분리
10. 거버넌스와 리스크 (1장) — 5문서, 상위 리스크 5개와 대응
11. 일정과 투입 구조 (1장) — 간트 표, 컨설턴트 투입 형태, 고객 측 역할(아트 디렉터·QA 오너·에이전트 운영자 지정)
12. 다음 단계 (½장) — NDA → 사전 자료 → 첫 미팅(반나절) → 진단 착수
부록 A. 첫 미팅 아젠다 요약  부록 B. 사전 요청 자료 목록  부록 C. 하네스 구성 예시(도구 이름 허용)  부록 D. 활용 가능 지원사업  부록 E. 용어
```
