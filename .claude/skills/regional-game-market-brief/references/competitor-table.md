# 경쟁작 비교표 형식

같은 장르(방치형 RPG) 3~4개를 고른다. 선정 기준: (1) 국내 스토어 상위 노출, (2) 대상사와 유사한 규모 1개 이상, (3) 대형사 진입작 1개 이상.

| 항목 | 관찰 방법 | 왜 보는가 |
|---|---|---|
| 출시 연도·운영 기간 | 스토어 | 선점 효과 비교 |
| 최근 3개월 업데이트 횟수·규모 | 스토어 변경 로그 | 콘텐츠 처리량 기준선 |
| 리뷰 수·평점 | 스토어 | 유저 규모 대리 지표 |
| 수익모델 노출 | 스토어 인앱 상품 목록·스크린샷 | 확률형 vs 비확률(스킨·패스) 비중 |
| 아트 밀도 | 스크린샷 | 에셋 생산량 요구 수준 |
| 플랫폼 | 스토어 | PC/스팀 확장 여부 |
| AI 활용 고지 | 스토어 페이지·커뮤니티 | 업계 공개 관행 |

표 아래에 "대상사 대비 위치" 3줄: 업데이트 빈도, 아트 밀도, 수익모델. 매출 추정치는 출처(센서타워 등) 없이는 쓰지 않는다.
