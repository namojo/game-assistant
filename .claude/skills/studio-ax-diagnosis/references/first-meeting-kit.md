# 첫 미팅 키트 구성 원칙

## 목표 문장
"진단할 수 있는 데이터를 확보하고, 게임·시장·지역을 이해했다는 신뢰를 주고, 3년 방향과 AX 범위를 합의한다." 해결책 제시는 목표가 아니다.

## 구조 (반나절 4시간)
- **세션 A 경영 워크숍 90분(전원)**: 오프닝(플레이 소감+리뷰 마이닝 화면 1장) → 지방 게임사 이슈 1장 → 트렌드 5장+토론 → 3년 후 모습(화이트보드) → 현 게임 수명 가정 → AI에 대한 회사 입장
- **세션 B 진단 워크숍 120분**: 경영진 목표 15 → 업데이트 1건 해부 30(핵심) → 아트 세션 20(원화가, 대표 없이) → QA·기술 세션 20(개발자) → 기대와 우려 15 → 휴식 겸 개별 대화 20
- **세션 C 종합 30분**: 3년 방향(시나리오 A/B/C) × 병목 → 우선순위 초안 그 자리에서 → 다음 단계 합의

## 사전 요청 (D-7, NDA 후)
"가능한 것만, 없으면 '없음'이라고" 명시. 카테고리: 조직·전략 / 사업·지표 / 개발 사이클(최근 업데이트 1건 기획서·일정·분배) / 아트(원본 파일 샘플, 스타일 가이드 유무) / 밸런스(테이블 샘플, 게임 반입 경로) / QA(방식, 체크리스트, 최근 3회 핫픽스 사유) / 기술(엔진 버전, 서버, 빌드, 자동화 테스트 개수) / 운영(월 티켓 수, 리뷰 답변 프로세스)

## 참석자
대표 + 기획 + 원화 + 개발 각 1인 이상. 경영진만의 미팅은 절반만 본 것.

## 관찰 포인트
대표가 실무 질문에 직접 답하는가 / 밸런스 시트를 여는가 코드를 여는가 / "○○님만 알아요" 횟수 / 원화가의 팔짱 / 핫픽스 사유가 밸런스인가 결제인가 / 3년 그림에서 대표·실무 답이 갈리는가 / 지방 이슈 슬라이드에서 끄덕이는 항목

## 어긋나는 지점 (하지 말 것)
도구 이름 먼저 / 경영진만 / 범위를 아트·QA로 잠금 / Quick Win 없이 진단만 / 브리핑 30분 초과 / 대형사 사례 길게 / 지방 이슈를 동정으로

## 미팅 후 D+3
미팅 노트(사실/미확인/인식 차이) → 워크플로우 맵 → 시나리오·우선순위 초안 → 진단 계획서 → 누락 자료 재요청 → Quick Win 착수
